# Jujutsu Survivors

Juego de navegador estilo *survivor* en pixel art, inspirado en Jujutsu Kaisen. Todo está en un solo archivo: `index.html`.

## Cómo jugar

Abre `index.html` en el navegador, o activa GitHub Pages en este repositorio (Settings → Pages → rama `main`, carpeta raíz).

| Acción | Teclas |
|---|---|
| Moverse | WASD / flechas (en el móvil, arrastrar el dedo) |
| Cambiar de técnica | 1 · 2 · 3 |
| Potenciadores (10 s, recarga 20 s) | Q velocidad · E daño · R ataque |
| Técnica máxima | Espacio |
| Infinito de Gojo (tras cada jefe) | F |
| Pausa | P |

- Personajes: Yuji, Megumi, Nobara y Gojo, cada uno con sus propias técnicas que se encuentran matando maldiciones.
- Mapa de Shibuya con edificios sólidos.
- Las grietas y Todo te llevan con los jefes: Jogo, Hanami, Dagon, Mahito, Mahoraga y Sukuna. Al ganar puedes mejorar o unir técnicas (por ejemplo, Azul + Rojo = Púrpura).

Proyecto de fans sin fines comerciales.
